# Странствующий торговец

Источник: предоставленный пользователем файл `торговец.glb` (47 564 828 байт).
Автор/условия лицензии исходной модели в файле не указаны; CC0 не заявляется.

Исходник: статичный меш, 499 656 треугольников, три PBR-текстуры 4096, без скелета и анимаций.
Игровая версия: 26 000 треугольников, 17 костей, рост 1.8 м, цвет 1024, нормали/ORM 512.
UV и исходный материал сохранены; добавлены idle/greet/talk/walk. Клипы созданы для этой модели,
не заимствованы из сторонних паков. walk — на месте, торговец в игре не патрулирует.

Сборка: tools/rig_trader_model.py → tools/import_trader_model.gd.
Сохраняются текстовые ресурсы Godot; исходный GLB в репозиторий не включён.
