# Очиститель воды

Источник: предоставленный пользователем `очи.glb`, 84 328 724 байта.
Автор и лицензия исходника не указаны; CC0 не заявляется.

Исходная модель исправного очистителя: 1 500 000 треугольников, один статичный
меш, три PBR-текстуры. Игровая версия: 32 000 треугольников, высота 2.15 м,
цвет 1024, нормали/ORM 512. Геометрия и UV исходной модели сохранены с упрощением.

Разрушенный очиститель создан из исправного: разломанная наклонённая колонна,
сорванный верхний обод/колено трубы, обломки, открытый фильтрующий материал,
грязь/ржавчина. 34 486 треугольников, тот же текстурный атлас; дополнительный
vertex color для повреждений. Авторские клипы/сторонние модели не использованы.

Создание: tools/create_water_filter_model.py (bpy 5.1.2).
Импорт: tools/import_water_filter_model.gd (Godot 4.7.2).
Игровые сцены: water_filter_repaired.tscn, water_filter_ruined.tscn.
Исходник и сборочные .gltf/.blend не нужны для запуска и не включены в репозиторий.
