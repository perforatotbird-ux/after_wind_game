## 🚀 Быстрый запуск игры

Для Windows подготовлен удобный лаунчер **`start.bat`**:

```cmd
# Запуск игры:
start.bat

# Запуск в редакторе Godot:
start.bat --editor

# Запуск интеграционных тестов (headless):
start.bat --test
```

## 🎮 Управление (Hotkeys)

- **W, A, S, D** — Перемещение персонажа в изометрии
- **Shift** (удержание) — Спринт (расходует бодрость)
- **E** — Взаимодействие (добыча жил, запуск станков, сбор урожая, диалоги с NPC)
- **1, 2, 3, 4, 5** — Хотбар слотов быстрого доступа
- **I** / **Tab** — Открытие инвентаря и крафта
- **C** — Окно выбора специализации (Шахтёр, Фермер, Учёный)
- **Y** — Быстрое поедание пищи для восстановления сытости
- **F5** / **F9** — Быстрое сохранение / Быстрая загрузка мира
- **ESC** — Меню паузы и чек-лист восстановления базы

## 🏆 Реализованные системы Главы 1 (Base Restored)

1. **Персонаж и выживание**: стамина, жажда, голод, промокание под дождем, тепло и сушка.
2. **Добыча и инвентарь**: 5 типов месторождений, система массы и слотов, хотбар.
3. **Станки и переработка**: дробилка, верстак, высокотемпературная печь-плавильня, фильтр воды, станция сбыта.
4. **Сельское хозяйство**: грядки, семена моркови, картофеля и пшеницы, полив дождем или вручную, удобрение.
5. **Энергосеть**: ветрогенератор со скоростью ветра, аккумуляторная батарея, автоматические уличные фонари.
6. **NPC и экономика**: караванщик Степан, доска объявлений, заказы и контракты.
7. **Ремонт базы**: 4 визуальные стадии жилого дома и склада продукции.
8. **Ролевая система**: 3 специализации (Шахтёр, Фермер, Учёный) с уникальными перками.
9. **Сохранения**: полная сериализация мира в JSON (`F5`/`F9`, автосейв при сне).
10. **Game Feel и аудио**: 11 процедурно синтезированных звуков (без тяжелых ассетов).
11. **Финал Главы 1**: победный триумф **«BASE RESTORED»** по 8 критериям дизайн-документа.
