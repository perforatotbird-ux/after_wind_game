## 🚀 Быстрый запуск игры

Для Windows подготовлен удобный лаунчер **`start.bat`**:

```cmd
# Запуск игры:
start.bat

# Запуск в редакторе Godot:
start.bat --editor

# Запуск интеграционных тестов (headless):
start.bat --test
```

## 🎮 Управление (Hotkeys)

- **W, A, S, D** — Перемещение персонажа относительно ракурса камеры
- **Shift** (удержание) — Спринт (расходует бодрость)
- **ЛКМ** — Удар инструментом (замах киркой/топором, добыча ресурсов, взаимодействие)
- **ПКМ** (зажать + движение мыши) — Орбита: вращение камеры вокруг персонажа
- **Колесо мыши** — Зум камеры (приближение 3.5 м / отдаление 26 м)
- **E** — Взаимодействие (добыча жил, запуск станков, сбор урожая, диалоги с NPC)
- **1, 2, 3, 4, 5** — Хотбар слотов быстрого доступа
- **I** / **Tab** — Открытие инвентаря и крафта
- **C** — Окно выбора специализации (Шахтёр, Фермер, Учёный)
- **Y** — Быстрое поедание пищи для восстановления сытости
- **F5** / **F9** — Быстрое сохранение / Быстрая загрузка мира
- **ESC** — Меню паузы и чек-лист восстановления базы

## 🏆 Реализованные системы Главы 1 (Base Restored)

1. **Персонаж и выживание**: стамина, жажда, голод, промокание под дождем, тепло и сушка.
2. **Добыча и инвентарь**: 5 типов месторождений, система массы и слотов, хотбар.
3. **Станки и переработка**: дробилка, верстак, высокотемпературная печь-плавильня, фильтр воды, станция сбыта.
4. **Сельское хозяйство**: грядки, семена моркови, картофеля и пшеницы, полив дождем или вручную, удобрение.
5. **Энергосеть**: ветрогенератор со скоростью ветра, аккумуляторная батарея, автоматические уличные фонари.
6. **NPC и экономика**: караванщик Степан, доска объявлений, заказы и контракты.
7. **Ремонт базы**: 4 визуальные стадии жилого дома и склада продукции.
8. **Ролевая система**: 3 специализации (Шахтёр, Фермер, Учёный) с уникальными перками.
9. **Сохранения**: сериализация основных систем мира в JSON (`F5`/`F9`, автосейв при сне).
10. **Game Feel и аудио**: 11 процедурно синтезированных звуков (без тяжелых ассетов).
11. **Финал Главы 1**: победный триумф **«BASE RESTORED»** по 8 критериям дизайн-документа.
12. **Анимации главного героя**: ретаргет Universal Animation Library 1/2 на модель шахтёра (`tools/retarget_ual_to_miner.gd`) — idle / walk / jog / run, удар киркой сверху вниз, рубка топором, вскопка, набор воды, полив, еда и др.; темп шага подгоняется под скорость.
13. **Камни**: стилизованные «рубленые» валуны из сланца по референсу (`tools/generate_rocks.gd`) — 1 большой валун (жила «Камень», добывается **киркой**, 10 штук на карте) и 3 малых декоративных (плита, скала-шпиль, голыш; 37 штук), раскиданы по всей карте вне двора базы.
14. **Деревья и лес**: стилизованные дубы и сосны по референсам (`tools/generate_trees.gd`) — 4 вида (дуб, молодой дуб, коническая и раскидистая сосна), рубятся **топором** в пенёк и дают древесину; небольшой лес из 38 деревьев на юго-западе карты + 4 дерева у базы.
14. **Реалистичные 3D-персонажи и анимации** (в работе, не влито в `main`): скелетные модели Шахтёра и Фермера (`.glb` из Blender), запечённые анимации `idle` / `walk` / `run` / `mine`, замах инструментом по **ЛКМ**, орбитальная камера (**ПКМ** + **колесо**), камеро-зависимое движение, 2D-портреты и изометрия-спрайты классов.

## 🧪 Запуск тестов

Нужны **Godot 4.7.x** и **Python 3.9+**. Проверено на Godot **4.7.2 stable** под Linux.
Blender не требуется для игры и тестов: используются готовые GLB/TSCN, импорт
исходников `.blend` отключён. Для работы с ними в редакторе включите
`filesystem/import/blender/enabled` и настройте Blender.

```bash
# Linux / macOS (или передайте полный путь к Godot):
python3 tools/run_tests.py --godot godot

# Windows:
.\start.bat --test

# Самопроверка тестового запуска:
python3 -m unittest discover -s tests -p 'test_*.py'
```

Запускаются все **22 GDScript-теста**: 11 этапных, 10 фичевых и один новый
тест регрессий аудита. Каждый — отдельным процессом, с ограничением времени
и отдельными пользовательскими сохранениями. На Windows/macOS для этого создаётся
временная копия проекта с уникальным именем; этот путь требует отдельной проверки
на этих платформах. Запуск не считает тест успешным при `ERROR` / `SCRIPT ERROR`, даже
если Godot вернул код 0. Логи и итоговый JSON: `outputs/test-results/`.
Пять Python-тестов проверяют обработку ошибок самим запуском.

GitHub Actions выполняет импорт, Python-тесты и весь набор Godot-тестов на Linux.
Результат CI смотрите в **Actions**, а не по статическому числу в README.

Подробности исправлений и оставшихся рисков: [CODE_AUDIT.md](docs/CODE_AUDIT.md).
