# prompts/

Служебные промпты для ИИ-ассистентов (например, `error check.txt` — проверка кода на ошибки).

Источник правды о механиках, форматах и тестах — [docs/DOCUMENTATION.md](../docs/DOCUMENTATION.md). Если промпт противоречит мастер-документу, прав мастер-документ. Промпты не дублируют описание систем, а ссылаются на него.
