# CloudByte / TGCloud Skill: Local & DB File Organization by Prefix

## Назначение
Данный навык (Skill) описывает процедуру автоматической сортировки и организующего перемещения файлов параллельно на локальном диске (корень `P:\`) и в виртуальной файловой системе PostgreSQL (корень `Drive P:\`).

---

## Ключевой Функционал и Компоненты

1. **Главный скрипт**: `organize.py` в корне репозитория (`K:\Test\Replit\organize.py`).
2. **Конфигурация префиксов**:
   Простой строковый синтаксис (без JSON) в формате:
   ```text
   PREFIX_RULES_TEXT = """
   FD = Fashion Dolls
   FK = Fashion Kingdom
   CC = CC
   """
   ```
3. **Принцип работы**:
   - Автоматически сопоставляет путь текущей директории `P:\...` с БД папки `Drive P:\...`.
   - Находит совпадение локальных файлов (`.mp4`) и записей в БД (`.rar`, `.mp4(...).rar`) по базовому имени (стему).
   - Создаёт необходимые подпапки локально и в БД (`FolderRepository.create_folder`).
   - Перемещает файлы локально и в БД (`VFile.folder_id`), после чего пересчитывает статистику объёмов (`FolderRepository.update_stats`).

4. **Механизм отката (`revert.py`)**:
   - При выполнении `organize.py` генерирует журнал операций `revert_journal.json` и готовый к исполнению скрипт `revert.py`.
   - В случае ошибки или команды на откат запуск `python revert.py` мгновенно возвращает все файлы локально и в БД в их исходные папки и с исходными именами.

## Инструкция по Использованию

### Запуск организации файлов:
```bash
# Перейти в целевую папку на диске P:\ (например, P:\Video\F\Fashionland Models\Name)
cd /d P:\Video\F\Fashionland Models\Name

# Запустить скрипт организации
python K:\Test\Replit\organize.py
```

### Добавление новых правил префиксов:
Отредактировать константу `PREFIX_RULES_TEXT` в `organize.py`, добавив правило `ПРЕФИКС = ИМЯ ПАПКИ` с новой строки.
