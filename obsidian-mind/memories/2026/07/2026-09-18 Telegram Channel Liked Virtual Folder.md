# Telegram Channel "Liked" Virtual Folder Optimization

## Проблема
При нажатии кнопки "I like It" (Star) на файле в Telegram Channels, плеер/интерфейс "тухнул" (подвисал) до завершения операции. Это происходило потому, что бекенд синхронно скачивал файл из Telegram на диск, чтобы импортировать его в VFS-папку `Liked` (`import_to_vfs`). Поскольку файл мог весить гигабайты, UI зависал.

Вторая проблема заключалась в том, что пользователь хотел видеть залайканные файлы Telegram каналов в единой виртуальной папке `❤ Liked` внутри самого раздела Telegram Channels, а не копировать их физически в VFS (Saved Messages).

## Решение

Была изменена архитектура работы с лайками в Telegram Channels:

### 1. Удаление блокирующего копирования (`backend/services/telegram_service.py`)
- Функция `like_and_import` была упрощена. Теперь она **не запускает** `import_to_vfs` и не скачивает файл с серверов Telegram.
- Она только ставит флажок `is_liked = True` в базе данных (`TelegramFile`).
- В результате лайк ставится **моментально**, интерфейс больше не блокируется.

### 2. Новый Endpoint для всех лайков (`backend/routers/telegram_channels.py`)
- Добавлен новый эндпоинт `GET /api/telegram-channels/all/liked-files`.
- В `query_files` параметр `channel_id` сделан опциональным (`Optional[int]`). Если он равен `None`, запрос игнорирует привязку к каналу и возвращает `TelegramFile` со всех каналов, отфильтрованные по `is_liked == True`.

### 3. Виртуальная папка "❤ Liked" во фронтенде (`TelegramBrowser.jsx`)
- В корень компонента TelegramBrowser (когда `channelId === null`) была добавлена фейковая виртуальная папка: `❤ Liked (All Channels)` красного цвета.
- При клике на неё `channelId` устанавливается в специальное значение `'liked-all'`.
- Когда `channelId === 'liked-all'`:
  - `loadFolders` не загружает подпапки.
  - `loadFiles` делает запрос к новому API-методу `allLikedFiles`, получая единую ленту избранных файлов со всех каналов.
  - Хлебные крошки (breadcrumbs) переключаются в режим отображения "❤ Liked (All Channels)".
  - Локальный фильтр-переключатель "Показать только Liked" скрывается, так как мы и так в папке Liked.
  - Тосты после лайка/дизлайка обновлены, чтобы не упоминать создание job'ов импорта.

## Итог
- Интерфейс мгновенно реагирует на лайки.
- Дисковое пространство сервера не забивается дубликатами.
- Все залайканные медиа из разных каналов удобно собраны в корневой папке Telegram Channels.
