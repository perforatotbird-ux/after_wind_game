# Media Player: Полноэкранный переход к следующему видео, кнопка I Like It и прекеширование (2026-09-10)

## 1. Контекст и цели
В рамках улучшения пользовательского опыта при просмотре мультимедиа (как в основном файловом менеджере VFS, так и в браузере Telegram-каналов TG Channels) реализованы ключевые функции:
1. **Переход к следующему видео в полноэкранном режиме**:
   - Специальная кнопка **Next Video** (`SkipForward`) в верхней панели плеера.
   - Боковые стрелки навигации (`ChevronLeft` / `ChevronRight`) теперь активны как для изображений, так и для видео.
   - Автоматический переход к следующему видео по окончании воспроизведения (`onEnded={() => onNext && onNext()}`).
   - Контейнерный полноэкранный режим (`Maximize` / `Minimize`), гарантирующий видимость и интерактивность всех контролов и кнопок поверх видео.
   - Поддержка горячих клавиш: `ArrowRight` / `N` (следующее видео), `ArrowLeft` / `P` (предыдущее видео), `L` (лайк), `F` (полный экран), `Esc` (закрытие).
2. **Кнопка "I Like It"**:
   - Интерактивная кнопка-сердечко в шапке `MediaPreview`.
   - В VFS (Dashboard) синхронизируется с `is_starred` через `fileApi.update` и локальный стейт элементов.
   - В TG Channels синхронизирует состояние `likedIds` и свойства файлов `is_liked`/`is_starred`.
3. **Фоновое прекеширование следующих 2 файлов**:
   - Автоматический предзапрос первых 256 КБ через HTTP Range (`bytes=0-262143`) для следующих двух медиафайлов в очереди.
   - Для не-нативных видеоформатов (`.avi`, `.mkv`, `.wmv`) предзапрос отправляется с флагом `?transcode=video`, что заранее инициирует серверное транскодирование в MP4 (faststart) и исключает задержку при переключении пользователем.

## 2. Изменённые компоненты
- `frontend/src/components/MediaPreview.jsx`:
  - Добавлена кнопка "I Like It" с иконкой `Heart` и анимацией активности.
  - Добавлена кнопка "Next Video" в Header для видео.
  - Стрелки навигации активированы для `isVideo`.
  - Элемент `<video>` снабжен событием `onEnded`.
  - Внедрен фоновый эффект предзагрузки (`upcomingFiles`) через fetch Range.
- `frontend/src/components/TelegramBrowser.jsx`:
  - Упорядочивание медиафайлов строго по индексу в общем списке (`videosInView`).
  - Расчет `upcomingFiles` и передача в `<MediaPreview>`.
  - Обработчик `toggleLike` для синхронизации лайков.
- `frontend/src/pages/Dashboard.jsx`:
  - Расчет упорядоченного списка `previewMediaList` с приоритизацией видео при активном видеофайле.
  - Расчет `upcomingPreviewFiles` (2 следующих медиафайла).
  - Интеграция `onLike` с вызовом `fileApi.update` и мгновенным обновлением UI через `handleItemsUpdate`.
