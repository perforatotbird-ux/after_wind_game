# Media Preview UI Improvements

В компонент `MediaPreview.jsx` были внесены два небольших, но важных улучшения UX:

1. **Защита от случайного закрытия**:
   - Ранее клик по пустой области вокруг медиа-файла приводил к закрытию полноэкранного просмотра (срабатывал `onClick={onClose}`).
   - Это мешало при просмотре. Обработчик `onClick={onClose}` был удален с обертки контента. Теперь окно закрывается только кнопкой "Крестик" или клавишей `Esc`.

2. **Навигация колесиком мыши для видео**:
   - Ранее колесиком мыши можно было переключать только картинки (`isImage`).
   - Логика была расширена (`!isImage && !isVideo`), что позволяет пролистывать видео (Next/Prev) с помощью колеса мыши точно так же, как и фотографии. Это значительно улучшает опыт просмотра лент в Telegram каналах, содержащих видео.
